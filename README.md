# 🚀 Ubuntu VPS Setup Script for VPN & Docker

Интерактивный bash-скрипт для автоматической первоначальной настройки и оптимизации чистого сервера на базе Ubuntu. 

Идеально подходит для слабых VPS (от 1 vCPU / 1 ГБ RAM). Скрипт минимизирует потребление ресурсов, настраивает сетевой стек, устанавливает базовые инструменты защиты и подготавливает среду Docker.

## ✨ Что делает скрипт?

*   **Оптимизация производительности**: Создает Swap-файл на 2 ГБ, включает алгоритм TCP BBR для ускорения сети и включает IP forwarding.
*   **Экономия ОЗУ**: Отключает тяжелые фоновые службы (`snapd`, `multipathd`) и ограничивает размер системных логов `journald` (до 200 МБ).
*   **Установка ПО**: Устанавливает Docker, UFW, Fail2ban, Certbot, `curl`, `git` и `dnsutils`.
*   **Безопасность (UFW)**: Автоматически открывает порты 22, 80, 443 и интерактивно запрашивает дополнительные порты.
*   **SSL-сертификаты**: Интерактивно выпускает сертификат Let's Encrypt (с предварительной проверкой привязки A-записи домена к IP-адресу сервера).
*   **WARP Native**: Автоматически устанавливает Cloudflare WARP.
*   **Рабочая среда**: Создает и подготавливает директорию `/opt/remnanode` (и `/opt/remnanode/certs/` для скопированных ключей SSL).

## 🛠 Требования

*   **ОС:** Ubuntu 20.04 / 22.04 / 24.04
*   **Права:** root (или пользователь с правами `sudo`)
*   *(Опционально)* Привязанный к IP сервера домен, если планируете выпускать SSL-сертификат.
